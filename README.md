# ChemCross

Tři interaktivní chemické křížovky. Autor zadání: Richard Kostrakiewicz.

## Vyzkoušení
Otevřete index.html v prohlížeči. Všechny tři HTML soubory musí zůstat ve stejné složce.
Podporuje českou diakritiku, místní ukládání a export/import rozehraných křížovek.
Kontrola správných odpovědí není součástí této verze.

## GitHub Pages
1. Vytvořte veřejný repozitář chemcross.
2. Nahrajte obsah této složky (nikoliv ZIP) do kořene repozitáře.
3. Settings → Pages → Build and deployment → Deploy from a branch.
4. Vyberte branch main a složku / (root), poté Save.
5. Po dokončení nasazení bude Settings → Pages obsahovat adresu webu.

Veřejné budou web i zdrojové soubory. Web nepoužívá externí skripty, analytiku ani databázi.
Rozehrané luštění se ukládá pouze v daném prohlížeči; mezi zařízeními použijte zálohu JSON.
Při přechodu z místního souboru na GitHub Pages přeneste postup exportem a importem.
